# 동종업계 재무 비교 (Peer Compare)

레드플래그 판정의 기준선을 만들기 위해 대상 기업을 동종업계와 비교한다.
"매출채권/매출 40%"처럼 절대 임계치로 애매한 경우, 업계 중앙값 대비 편차로 보완한다.

## 사전 조건

`dart-screener` 스킬과 동일 — `DART_API_KEY` 필요. 키가 없으면 발급 안내
(https://opendart.fss.or.kr) 후 중단. 키를 채팅·출력에 노출하지 않는다.

스크립트는 이웃 스킬의 것을 재사용한다: `../dart-screener/scripts/dart_client.py`
(이 스킬 디렉토리 기준 상대 경로. 같은 플러그인에 함께 설치된다.)

## 실행 절차

### 1단계 — 대상 기업 식별

```bash
python3 ../dart-screener/scripts/dart_client.py find "기업명"
```

### 2단계 — 피어 선정

1. 사용자가 비교 대상을 지정했으면 그대로 사용한다.
2. 지정하지 않았으면 같은 업종의 대표 상장사 2~4곳을 제안하고 사용자 확인을 받는다.
3. 선정한 피어는 업종코드로 교차 확인한다:

```bash
python3 ../dart-screener/scripts/dart_client.py company <corp_code>
```

- `induty_code`(한국표준산업분류)가 대상 기업과 다르면 리포트에 그 사실을 명시한다
  (사업 구조가 달라 비교 한계 있음).

### 3단계 — 지표 수집

대상 + 피어 전부에 대해 동일 조건으로 수집한다:

```bash
python3 ../dart-screener/scripts/dart_client.py metrics <corp_code> --years 3
```

- 연결(CFS) 기준 통일. 실패한 기업만 `--fs OFS` 폴백하되 리포트에 기준 차이를 명시한다.

### 4단계 — 비교 판정

비교 지표 (metrics 출력 필드):

| 지표 | 필드 | 이상 판정 기준 |
|---|---|---|
| 매출채권/매출 비중 | `receivables_over_revenue_pct` | 피어 중앙값의 2배 초과 |
| 매출총이익률 | `gross_margin_pct` | 피어 중앙값 대비 ±15%p 이상 |
| 영업이익-현금흐름 괴리 | `oi_minus_cfo_over_assets_pct` | 피어 중앙값 대비 +10%p 이상 |
| 재고 증가율 | `inventories_growth_pct` | 피어 중앙값 대비 +20%p 이상 |
| 충당부채 증가율 | `provisions_growth_pct` | 피어는 증가하는데 대상만 급감 |
| 무형자산 증가율 | `intangibles_growth_pct` | 피어 중앙값 대비 +30%p 이상 |

- 피어가 2곳이면 중앙값 대신 범위(min~max)를 쓰고 그 사실을 명시한다.
- 지표 N/A인 기업은 해당 지표 비교에서 제외하고 각주로 밝힌다.

### 5단계 — 리포트

```markdown
# [대상 기업] 동종업계 비교 리포트
- 대상: [기업명] / 피어: [기업명들] (업종코드 병기) / [연도범위] [연결|별도]
- 데이터 출처: DART Open API

## 비교 테이블
(연도별 × 지표별 — 대상은 굵게, 이상 편차 셀은 ⚠️ 표시)

## 이상 편차 항목
(지표별: 대상 값 vs 피어 중앙값, 편차 크기, 가능한 해석)

## 권고
- 편차 항목이 있으면: "dart-screener 스킬로 [기업명] 정밀 레드플래그 점검을 권장"
- 비교 한계 고지 (업종코드 차이, 회계정책 차이, 연결 범위 차이)
```

## 절대 규칙

- 편차는 "업계 대비 이상 신호"일 뿐 분식 판정이 아니다. 단정 표현을 쓰지 않는다.
- 모든 비교에 실제 수치를 병기한다.
- 피어 선정 이유(왜 이 기업들인지)를 리포트에 남긴다.
